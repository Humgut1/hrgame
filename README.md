# HR 실무 시뮬레이터

HR 주니어와 취준생이 **실제 회사에서 일하는 것처럼** HR 의사결정을 연습하는 웹 시뮬레이터.

문제가 출제되지 않는다. 상황이 사내 메신저로 도착할 뿐이다. 정보는 늘 부족하게 시작하고,
되물어야 나온다. 정답은 없고 트레이드오프만 있다.

> 등장하는 회사·인물·데이터는 전부 가상이다. 실제 기업이나 개인과 무관하다.

---

## 무엇을 하는 게임인가

현재 구현된 스테이지는 **채용 03 — 오퍼 협상** 1건이다. 1회 플레이 약 10분.

3개월 걸린 백엔드 시니어 채용의 마지막 관문. 최종 합격자는 연봉 밴드 상단을 800만원 넘는
금액을 요구하고, 회신 기한은 오늘 오전 11시다. 요구를 맞추면 기존 재직자와의 형평성이 깨지고,
못 맞추면 3개월이 무산된다.

플레이어는 두 NPC와 대화한다.

| NPC | 역할 | 압력 방향 |
|---|---|---|
| 김도현 | 플랫폼팀장 (채용 요청 부서장) | 무조건 잡아라 |
| 박서연 | 피플팀장 (플레이어의 사수) | 근거와 형평성을 대라 |

**결정적인 정보는 각자 한 명씩만 쥐고 있다.** 한 명만 붙잡으면 절반만 보이도록 설계했다.
메시지 1건에 12분이 흐르고, 총 8턴 안에 끝내야 한다.

제출한 오퍼는 5개 축(채용 성사 · 내부 형평성 · 비용/절차 · 이해관계자 신뢰 · 데이터 근거성)으로
채점되고, 후보자 회신과 D+21 후속 결과가 담긴 리포트를 받는다.

## 설계에서 지킨 경계

이 프로젝트의 핵심은 **LLM에게 무엇을 맡기지 않았는가**에 있다.

**진행은 상태머신이 소유하고 LLM은 대사만 생성한다.**
국면 전환(브리핑 → 조사·협상 → 결정 → 결과)을 LLM이 결정하게 두면 3턴 만에 NPC가
정답을 알려주며 게임이 붕괴한다. 턴 회계는 클라이언트와 서버가 각각 센다.

**숨은 정보의 공개 판정은 서버가 한다.**
`gateSecrets`가 신뢰도와 키워드로 통과시킨 secret만 프롬프트에 실린다. 허용되지 않은 정보는
프롬프트에 아예 존재하지 않으므로 LLM이 흘릴 수가 없다. 응답의 신뢰도 변화량도 서버가 범위로 다시 조인다.

**NPC별 데이터 격리는 선언으로 한다.**
시나리오 JSON의 NPC마다 접근 가능한 회사 데이터 경로를 적고, 그 경로만 프롬프트에 실린다.
"두 사람 모두와 이야기해야 한다"는 게임 규칙이 프롬프트 지시가 아니라 데이터 구조에서 나온다.

**페널티와 총점은 코드가 판정한다.**
밴드 초과·결재 한도 위반처럼 숫자로 판정 가능한 것은 `detectPenalties`가 비교하고,
모델에게는 결과를 사실로 준다. 판정을 프롬프트로 부탁하면 상한이 걸릴지가 모델 기분에 달린다.
모델은 축별 점수와 코멘트만 낸다.

**API 키는 클라이언트에 닿지 않는다.**
Anthropic SDK 호출은 Route Handler(`/api/npc`, `/api/grade`)에서만 일어난다.
클라이언트로 넘기는 시나리오는 `toClientScenario()`를 통과해 secrets가 제거된다.

**시나리오는 콘텐츠지 코드가 아니다.**
회사·NPC·문서·채점 루브릭이 전부 `data/` 아래 JSON에 있다. 스테이지를 추가하는 일이
개발 작업이 되면 안 된다.

## 기술 스택

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Anthropic SDK

ORM 없음. UI 라이브러리 없음. 상태 저장은 localStorage.

## 구조

```
app/
  api/npc/          NPC 응답 생성 (서버 전용)
  api/grade/        오퍼 채점 (서버 전용)
  workspace/        게임 셸 — 브리핑 · 메신저 · 자료실 · 오퍼 · 리포트
lib/
  game/state.ts     세션 타입 + 순수 리듀서 (턴·시각·국면·실패 롤백)
  game/secrets.ts   숨은 정보 공개 판정
  game/offer.ts     오퍼 검증 + 페널티 판정 + 총점
  llm/npc-prompt.ts NPC 프롬프트 조립 (정보를 가려서 넣는다)
  llm/grade-prompt.ts 채점 프롬프트 (전부 넣는다)
data/
  schema/           JSON 스키마 2종
  companies/        회사 마스터 데이터
  scenarios/        시나리오
scripts/
  validate-data.mjs 무의존 구조·참조 무결성 검증기
```

`docs/기획서.md` 가 기획·설계의 단일 출처다.

## 실행

Node.js 20 이상이 필요하다.

```bash
npm install
```

Anthropic API 키를 설정한다. `NEXT_PUBLIC_` 접두사를 붙이면 브라우저로 새어나가므로 절대 붙이지 않는다.

```bash
cp .env.example .env.local
```

`.env.local` 에 `ANTHROPIC_API_KEY` 를 채운 뒤 실행한다.

```bash
npm run dev
```

http://localhost:3000 에서 열린다.

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드 |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run validate` | 데이터 구조·참조 무결성 검증 |

`npm run dev` 가 떠 있는 동안 `npm run build` 를 돌리지 않는다. 둘이 같은 `.next` 를 쓴다.

NPC 대화와 채점은 실제 Anthropic API를 호출하므로 플레이할 때마다 토큰 비용이 발생한다.
